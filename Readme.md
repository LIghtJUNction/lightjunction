### 🛠️ 有趣的工具 (Interesting Tools)

<details>
  <summary>展开查看推荐工具</summary>

#### 开发工具
- **[HTTPie](https://httpie.io/)** - 现代化的命令行 HTTP 客户端，比 curl 更友好
- **[jq](https://stedolan.github.io/jq/)** - 命令行 JSON 处理器，轻量且强大
- **[fzf](https://github.com/junegunn/fzf)** - 命令行模糊查找工具，提升终端效率
- **[ripgrep](https://github.com/BurntSushi/ripgrep)** - 超快的文本搜索工具，替代 grep

#### 实用工具
- **[tldr](https://tldr.sh/)** - 简化版命令文档，快速查看常用命令示例
- **[Tokei](https://github.com/XAMPPRocky/tokei)** - 代码统计工具，快速统计项目代码行数
- **[bat](https://github.com/sharkdp/bat)** - cat 的替代品，带语法高亮的文本查看器
- **[exa](https://github.com/ogham/exa)** - 现代化的 ls 替代品，功能更丰富

#### Python 工具
- **[Rich](https://github.com/Textualize/rich)** - Python 终端美化库，支持表格、进度条等
- **[Typer](https://github.com/tiangolo/typer)** - 基于类型提示的 CLI 构建工具
- **[httpx](https://github.com/encode/httpx)** - 下一代 HTTP 客户端，支持异步
- **[Pydantic](https://github.com/pydantic/pydantic)** - 数据验证库，使用 Python 类型注解

#### 网络工具
- **[Clash Verge](https://github.com/clash-verge-rev/clash-verge-rev)** - 跨平台代理工具
- **[v2rayA](https://github.com/v2rayA/v2rayA)** - Web GUI 的 V2Ray 客户端
