旗舰与肉鸽

WASD / 方向键移动，自动瞄准开火。空格冲刺，E 释放脉冲。捡经验后暂停三选一。旗舰损毁会让基地失去 40 点生命，8 秒后重生；基地被摧毁才会结束。

建塔与生产

打开「建造」选择建筑，再点地面放置。点击已建建筑可升级、修复或回收。「小队」中训练单位，单位会前往集结点。矿机提供持续收入，修复中继保养附近友军。单位与敌人悬浮移动，建筑不会封路；这是火力布防，不是堵路迷宫。

指挥

点击 / 框选单位，Shift 加选，F 全选。右键或 G 指定移动，T 进攻移动，H 原地驻守。进攻移动会停下迎敌。手机使用「全选」和「指令」，再点击目的地；左下摇杆驾驶旗舰。

滚轮缩放，中键或按住 Q 拖动平移；点小地图跳转镜头。Esc 暂停或取消建造。隐藏标签页会自动暂停。本局不跨刷新保存；只有最高波数与分数保存在本机，不调用模型，也不消耗 API 额度。
