RUST LIBRARY COLLECTION

Project Z.

Small components. More room to build.

A collection of small, composable Rust libraries for protocols, terminals, systems, and AI tooling. Each component has a focused job, with attention to runtime cost, memory use, and dependency size.

01

Data & protocols

Encoding, byte search, and message parsing. Reusable pieces for moving and interpreting data.

02

Terminals & systems

Command-line parsing, terminal output, system sampling, and native plugin interfaces.

03

AI infrastructure

Protocol conversion, model calls, tool loops, and MCP. Combine the capabilities your application needs.
