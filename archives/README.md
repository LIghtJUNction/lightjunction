# Weekly Report Archives

This directory contains archived weekly activity reports from the GitHub profile README.

## Structure

- `weekly_reports/` - Contains weekly report archives in Markdown format

## Retention Policy

- Maximum: **208 archives** (4 years of weekly reports)
- Format: `weekly_report_YYYYMMDD_HHMMSS_microseconds.md`
- Older archives are automatically deleted when the limit is reached

## Viewing Archives

You can browse historical weekly reports by accessing the files in the `weekly_reports/` directory. Each archive is a snapshot of the README at the time of archival.

The current README always includes a link to the most recent archived report in the "本周活动摘要 (Weekly Activity Summary)" section.
